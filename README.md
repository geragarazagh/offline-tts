# Offline TTS

Reads text aloud into an audio file with the computer's own voices, offline.

## Install

Terminal agents:

```sh
npx skills add geragarazagh/offline-tts -g
```

Claude Code:

```sh
claude plugin marketplace add geragarazagh/offline-tts
claude plugin install offline-tts@offline-tts
```

Gemini CLI:

```sh
gemini extensions install https://github.com/geragarazagh/offline-tts
```

Any other agent: paste the text of [`SKILL.md`](skills/offline-tts/SKILL.md) into its instructions.
